# ⌚ Luxury Watch Price Prediction & Intelligence

An end-to-end Machine Learning project that predicts the estimated market price and price category of luxury watches based on their specifications.

## 🚀 Live Demo

👉 https://watch-price-prediction.streamlit.app/

## 📂 GitHub Repository

This project covers the complete Machine Learning workflow — from data preprocessing and exploratory data analysis to model development, hyperparameter tuning, and deployment.

## 🎯 Project Objectives

The main objectives of this project are:

- Predict the estimated market price of a luxury watch.
- Classify watches into different price categories.
- Build an interactive web application for real-time predictions.
- Deploy the complete ML solution for public use.

## 🧠 Machine Learning Models

### 💰 Price Prediction

A **Random Forest Regressor** was developed and optimized using hyperparameter tuning.

**Final Model Performance:**

- MAE: 7,562.44
- RMSE: 61,476.60
- R² Score: 0.299

### 🏷️ Watch Category Classification

Watches were classified into four categories:

- Basic
- Mid
- Premium
- Luxury

A **Tuned Random Forest Classifier** achieved:

- Accuracy: 79.90%
- Precision: 79.65%
- Recall: 79.90%
- F1 Score: 79.69%

## 📊 Features Used

The models use important watch specifications including:

- Brand
- Model
- Reference
- Condition
- Gender
- Year of Production
- Watch Size

The Streamlit application allows users to enter watch specifications and receive:

- Predicted watch category

## ⚠️ Disclaimer

The predicted prices are machine learning estimates based on historical watch listings. Actual market prices may vary depending on factors such as rarity, condition, authenticity, demand, limited editions, and market fluctuations.
